# 2026-27 5대 리그 선수 데이터 통합

- 프리미어리그 20개, 라리가 20개, 분데스리가 18개, 세리에 A 20개, 리그 1 18개 구단.
- 사용자 제공 선수 CSV 2,773행을 중복 정리한 2,748명 + CSV에 없던 지정 U21 1군 출전 선수 2명 = 총 2,750명.
- CA/PA 표에 포함된 선수 223명은 원본 CA·PA를 각각 2로 나눠 현재 능력치와 잠재 능력치로 적용.
- 표에 없는 선수는 구단 전력·포지션·기존 선수 역할을 기준으로 추정. Transfermarkt 시장가치는 능력치 산정에 사용하지 않음.
- 스페인·독일·이탈리아·프랑스 선수는 CSV의 기본 포지션을 사용하고 세부 역할을 분류. EPL은 CSV에서 포지션이 `Unknown`으로 제공되어 기존 선수 데이터와 구단별 포지션 균형으로 추정.
- 세부 속성은 경기 엔진 내부 계산용이며 UI에는 주 포지션·세부 역할·특장점 2개만 노출.
- CSV에 나이·국적·공격포인트·패스 성공률·기회 창출 데이터가 없으므로 나이·국적은 미상이며, 세부 포지션과 일부 능력치는 추정값을 포함.
- U21은 사용자가 지정한 1군 공식 경기 출전 선수만 표시하고, CSV에 이미 존재하면 중복 생성하지 않음.
